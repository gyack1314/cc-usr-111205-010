# 联合分位拟合的实现与保证范围

本说明对应 `response_data` 内的纯标准库实现，配合 [资料约定](data-contract.md)
阅读。所有数值都可用 CLI 的 JSON 输出逐行重算。

## 模块划分

| 模块 | 职责 |
| --- | --- |
| `lp.py` | 两阶段单纯形，求解非负变量线性规划；区分 `optimal` / `infeasible` / `unbounded` / `iter_limit`，输出原始解、对偶变量、原始/对偶可行性残差与对偶间隙。未收敛状态不会被报成最优。 |
| `geometry.py` | 在**原协变量单位**判定点是否属于给定顶点的有界凸包，见证为非负重心权重（和为 1、重建出该点）。成员判定本身是一个等式 LP。 |
| `preprocess.py` | 仅用训练窗完整行锁定加权中心与正 scale；标准差为零的维度固定 scale=1 并登记 `constant`。验证行、外期行、顶点只套用同一变换。 |
| `quantile.py` | 一个 LP 联合拟合全部分位，含顶点不交叉约束与斜率 L1；独立重算目标并报告设计矩阵秩诊断。 |
| `pipeline.py` | 配置校验、按完整过程的时间前推验证、lambda 选择、全开发重拟合冻结、外期域内/域外分列评分。 |

## 联合 LP 的变量与目标

设计行 `z=[1, 标准化协变量]`，预测 `q_k = β_k'z`。所有 LP 变量非负：

- 残差拆为 `r = y - q = u - v`，`u,v >= 0`，最优解互补 `u·v=0`，
  于是 `pinball_τ(r) = τ·u + (1-τ)·v`。
- 自由系数拆为 `β = β+ − β−`，两者非负。斜率 L1 变为
  `λ·(β+ + β−)`，**截距列不惩罚**。
- 目标为各分位、各完整训练行的正权重 pinball 之和加上述惩罚；
  分位之间不设隐藏权重差。

## 不交叉保证的确切范围

对相邻分位 `k,k+1`，在调用者给出的**每个公开顶点** `v` 上施加
`q_{k+1}(v) − q_k(v) >= 0`。因为预测对系数是线性的，凸包内任意点
`p = Σ λ_v v`（`λ_v>=0, Σλ_v=1`）的分位差是顶点非负差的凸组合，故
整个凸包内不交叉。该保证：

- 由顶点约束推出，**不依赖训练样本点**，也不只在样本点上检查；
- 只对给定顶点张成的凸包成立，不推广到整个实空间；
- 凸包外的预测只标 `outside_domain_no_guarantee`，评分单列为辅助结果。

## 解的非唯一性与数值声明

LP 可能有多组最优系数。输出只声明这组系数在求解器容差内满足目标与
全部约束（含顶点不交叉），并附独立重算的目标、LP 内部目标及二者差、
原始/对偶残差和对偶间隙，不声称系数唯一。恒定协变量与设计矩阵秩不足
在 `diagnostics` 中单列。

## 前推验证与冻结

- 折叠以 `process` 整组切分，验证过程的 `time` 必须晚于全部训练过程，
  首折之后训练集必须恰为此前各折过程的并集。
- 每折独立锁定该折训练窗的中心/scale，对同一非负 lambda 网格拟合并在
  验证完整行上计**未惩罚** pinball。
- 选择指标 = 各折逐分位损失总和 / 全部验证行权重和；网格升序，平局取
  较大 lambda。任一折未达最优的 lambda 记为不可选，全失败则报错。
- 选定后在**全开发窗**重新锁定中心/scale 并重拟合一次，随后冻结。
  外期 `y` 的改动只改变外期评分，无法回到前面任何步骤改变系数
  （有专门测试锁定这一性质）。

## 外期评分口径

每个外期完整行先做凸包成员判定再预测，逐行给出正负残差与各分位
pinball，可独立重算。汇总按域内/域外分别给出：分位 pinball 总和、
单位权重损失、加权覆盖比例 `Σw·1(y<=q)/Σw` 与有效人数/权重。
覆盖是**聚合经验量**，不是逐样本区间保证；lambda 选择带来的不确定性
未计入，报告中显式声明这两点。缺 `y` 或缺任一协变量的行不参与拟合，
并在外期报告中列出标识。
